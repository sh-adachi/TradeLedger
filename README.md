# TradeLedger

日々の資産額と入出金から、トレード収支を振り返る日本語 iPhone アプリです。SwiftUI と Swift Charts で作成し、データは端末内に保存します。

[TradeNote の App Store 紹介](https://apps.apple.com/jp/app/tradenote/id1509383972)を機能の参考にしています。TradeLedger の画面、配色、アイコン、コードは独自に作成したものです。TradeNote の公式アプリ・関連製品ではありません。

## できること

- 運用開始時の資産額を設定し、日付ごとの資産残高・入金・出金・タグ・メモを記録
- ホームで現在の資産額、累計収支、月の成績、資産推移を確認
- カレンダーと履歴から記録を振り返り、編集・削除
- 収支、勝率、プロフィットファクター、最大ドローダウンを分析
- CSV の書き出し、JSON バックアップの書き出し・復元
- 明示的に選んだ場合だけデモデータを表示し、終了後に元のデータへ戻る

## 計算と入力のルール

```
記録日の収支 = 今回の資産残高 − 前回の資産残高 − 入金 + 出金
累計収支     = 各記録日の収支の合計
```

最初の記録は「前回の資産残高」に運用開始時の資産額を使います。たとえば、前回 100 万円・今回 115 万円・入金 10 万円・出金 2 万円なら収支は **+7 万円** です。過去の残高や入出金を編集・削除すると、その後の差額と成績も再計算されます。

- 円建ての整数を扱います。開始残高・資産残高・入金・出金はそれぞれ 0〜1 兆円です。負の資産残高や小数、他通貨には対応していません。
- 1 日 1 記録です。日付は日本時間（Asia/Tokyo）のグレゴリオ暦で扱い、未来の日付は登録できません。
- 記録しなかった期間の増減は次の記録に含まれます。その期間の入出金は次の記録で合計して入力してください。勝率などは取引単位ではなく、記録した日付の単位です。
- 勝率は「収支がプラスの日 ÷ 収支がゼロ以外の日」です。収支ゼロの日は母数に含めません。
- プロフィットファクターは利益合計 ÷ 損失合計の絶対値です。損失がない場合は数値を表示しません。
- 最大ドローダウンは、対象期間の入出金調整後の累積収支を 0 円から積み上げ、過去のピークから最も下がった金額です。口座残高に対する割合ではありません。
- 手数料・税金・含み損益は、入力した残高に含まれていれば収支にも反映されます。個別の約定管理、証券口座との連携、相場取得、税額計算はありません。
- メモは 2,000 文字、タグは 40 文字、記録は 100,000 件までです。

## 保存とバックアップ

アカウント登録・外部サーバーへの送信・広告・解析 SDK はありません。アプリはローカルの JSON ファイルへ保存し、更新前の有効なデータを復旧用に保持します。デモは一時的なデータとして扱い、通常の記録を上書きしません。

設定から JSON バックアップを書き出すと、「ファイル」など任意の場所へ保存できます。復元は確認後に現在の記録を置き換えます。ファイルの形式・バージョン・金額・日付・重複を確認し、50 MB を超えるファイルは読み込みません。CSV は表計算ソフト向けの書き出し専用で、数式として解釈されるメモやタグの先頭をエスケープします。共有したファイルには資産額やメモが含まれます。

アプリ削除や端末故障に備え、必要な記録は JSON で別の場所へ保存してください。専用の iCloud 同期機能はありません。

## 開発環境

- macOS / Xcode 26 以降
- iOS 17 以降の iPhone
- Swift 5 モード / SwiftUI / Swift Charts
- 外部パッケージ依存なし。`TradeLedgerCore` は同じリポジトリ内の Swift Package です。

`TradeLedger.xcodeproj` を開き、`TradeLedger` スキームと iPhone シミュレータを選んで実行します。実機では Xcode の **Signing & Capabilities → Team** にご自身の開発チームを設定してください。Bundle ID は `dev.adachi.tradeledger` です。

接続した iPhone へのビルド・インストール・起動は次のコマンドでも行えます。Xcode に Apple アカウントを追加し、iPhone を信頼済みにして開発者モードを有効にしてください。UDID と Team ID は引数で指定し、リポジトリには保存しません。

```sh
xcrun xctrace list devices
./Scripts/deploy_iphone.sh '<iPhone の UDID>' '<10 文字の Team ID>'
```

実機用の署名は開発用です。App Store への公開や TestFlight 配信は含みません。

```sh
# 計算・入力検証・永続化などの単体テスト
./Scripts/test_core.sh

# iPhone シミュレータでビルド
./Scripts/build_simulator.sh

# 初回設定 → 入出金を含む記録 → 編集、デモの分離、タブ移動の UI テスト
./Scripts/test_ui.sh
```

シミュレータの既定値は `iPhone 17 Pro` です。利用可能な別の端末に変える場合は、たとえば `SIMULATOR_DESTINATION='platform=iOS Simulator,name=iPhone 16' ./Scripts/test_ui.sh` を実行します。ログと UI テストの結果・スクリーンショットは `Artifacts/` に保存し、Git には含めません。

起動引数 `--uitesting` は通常の保存ファイルを使わない検証用モード、`--demo` は一時的なデモデータを表示するモードです。通常起動は初回設定から始まります。

## 構成

```text
TradeLedger/             SwiftUI 画面、アプリの状態管理、アセット
Sources/TradeLedgerCore/ データモデル、計算、検証、保存、バックアップ、CSV
Tests/                  Swift Package の単体テスト
TradeLedgerUITests/     XCTest による操作テスト
TradeLedger.xcodeproj/  iPhone アプリの Xcode プロジェクト
Scripts/                ビルド、テスト、独自アイコン生成
Docs/                   実装仕様
```

アイコンは `Scripts/render_icon.swift` の独自ベクター描画から生成しています。macOS 上でリポジトリのルートから `swift Scripts/render_icon.swift` を実行すると再生成できます。
